개인정보처리방침

시행일: 2026년 9월 16일

QA PLUS는 이용자의 개인정보를 중요하게 생각하며, 관련 법령과 Google OAuth 정책을 준수합니다.

1. 수집하는 정보

QA PLUS 웹사이트는 일반적인 방문 과정에서 사용자가 직접 입력하지 않는 한 별도의 개인정보를 수집하지 않습니다.

일부 서비스에서 Google 계정 인증이 사용되는 경우, 해당 기능 제공을 위해 사용자가 승인한 범위 내에서 필요한 인증 정보를 처리할 수 있습니다.

2. 개인정보 이용 목적

수집 또는 처리되는 정보는 다음 목적에 한하여 이용합니다.

  • QA PLUS 서비스 제공 및 운영
  • 사용자 인증
  • 서비스 오류 확인 및 개선
  • 사용자가 요청한 기능의 제공

3. 제3자 제공

QA PLUS는 법령에 따른 경우를 제외하고 이용자의 개인정보를 제3자에게 판매하거나 임의로 제공하지 않습니다.

4. Google API 서비스 이용

QA PLUS의 일부 자동화 기능은 Google API를 사용할 수 있습니다. 이 경우 Google 계정을 통해 사용자가 명시적으로 승인한 권한만 사용합니다.

Google API로부터 획득한 정보의 사용 및 전송은 Google API Services User Data Policy를 준수합니다.

5. 정보 보관 및 삭제

서비스 제공에 필요하지 않게 된 개인정보는 관련 법령 또는 서비스 운영에 필요한 기간을 제외하고 삭제합니다.

6. 이용자의 권리

이용자는 본인의 개인정보와 관련하여 열람, 수정 또는 삭제를 요청할 수 있습니다.
